# AI Hoshino

テスト粒子の軌道データを用いて、捕捉粒子（trapped）と通過粒子（passing）を分類する機械学習実験です。  
軌道データの生成、機械学習用データの準備、ラベルの作成、1 次元 CNN の学習と評価までを行います。

## 処理の流れ

```text
テスト粒子の軌道データを生成
              ↓
機械学習用データを準備
              ↓
位相運動に基づいてラベルを作成
              ↓
CNN を学習・評価
```

Notebook は、ファイル名の先頭にある番号の順に実行してください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `01_simulation_particle_data.ipynb` | Hoshino モデルのパラメータを設定し、テスト粒子の軌道を生成して、位相空間と共鳴領域を確認します。 |
| `02_ml_data_preparation.ipynb` | 粒子の初期条件をランダムにサンプリングし、長時間の軌道計算を行って、機械学習用の時系列データを作成します。 |
| `03_label_generation.ipynb` | 位相をアンラップして粒子ごとの位相変化を解析し、trapped / passing ラベルと訓練・検証・テスト用のデータ分割を作成します。 |
| `04_cnn_training.ipynb` | 速度と位相の特徴量を前処理し、1 次元 CNN を学習して、precision、recall、F1 score で分類性能を評価します。 |
| `data/ml_dataset/labels_and_split.npz` | 粒子ラベルと、訓練・検証・テストデータのインデックスを保存した小容量ファイルです。 |
| `.gitignore` | Notebook のキャッシュ、生成物、GitHub のファイルサイズ制限を超えるデータを Git の管理対象から除外します。 |
